## Accent color

Set `theme.accent` in `src/shared/config/site.ts`. It sets the Fumadocs primary color, which its components use for active and selected states. The text color on top of it is chosen from the color's lightness, so any CSS color works.

```ts title="src/shared/config/site.ts"
theme: {
  accent: { light: "oklch(0.55 0.2 260)", dark: "oklch(0.75 0.15 260)" },
},
```

Leave it as `null` to keep the neutral black theme.

## Radius

Set `theme.radius` in `src/shared/config/site.ts` to change the corners of cards, callouts, code blocks, search, buttons and the rest of the site with one value. It is a CSS length: `px`, `rem`, `em` or `0`.

```ts title="src/shared/config/site.ts"
theme: {
  accent: null,
  radius: "1rem",
},
```

The value is the size of the `xl` step, which cards, callouts and code blocks use. Every other step of the Tailwind radius scale keeps its proportion to it, so small elements such as buttons and keys scale down with it. `"0"` makes every corner square, and `rounded-full` elements such as pills stay round. Leave it out to keep the default of `0.75rem`.

| `radius`    | Look                |
| ----------- | ------------------- |
| `"0"`       | Square corners      |
| `"0.5rem"`  | Slightly rounded    |
| `"0.75rem"` | The default         |
| `"1.5rem"`  | Large, soft corners |

## Logo

`logo.src` takes a path in `public`, a URL, inline SVG markup or a React component. `darkSrc` is shown in dark mode and takes the same formats. `width` and `height` are the displayed size in pixels. The site name stays next to the logo unless `hideName` is set, and then `alt` describes the logo.

```ts title="src/shared/config/site.ts"
logo: {
  src: "/logo.svg",
  darkSrc: "/logo-dark.svg",
  width: 20,
  height: 20,
},
```

A component receives `width`, `height` and `className`, so SVGR output and icons from an icon library work. Inline SVG markup and components can use `currentColor` to follow the theme.

```tsx title="src/shared/config/site.ts"
import { Book } from "lucide-react";

logo: { src: Book, width: 20, height: 20 },
```

## Favicon

`favicon` takes a path in `public`, a URL or inline SVG markup. Use `{ light, dark }` for separate icons per color scheme.

```ts title="src/shared/config/site.ts"
favicon: "/favicon.svg",
// or
favicon: { light: "/favicon-light.svg", dark: "/favicon-dark.svg" },
```

Without `favicon`, an `icon.svg` or `icon.png` in `src/app` is used.

## Theme preset

The colors come from the Fumadocs theme imported in `src/app/globals.css`. Swap `black.css` for another file from `fumadocs-ui/css`, such as `neutral.css`, `ocean.css` or `emerald.css`.

```css title="src/app/globals.css"
@import "fumadocs-ui/css/ocean.css";
```

## Individual colors

Override any Fumadocs variable in `src/app/globals.css`, in `:root` for light mode and `.dark` for dark mode.

```css title="src/app/globals.css"
:root {
  --color-fd-background: hsl(40 30% 98%);
}

.dark {
  --color-fd-border: hsl(0 0% 20%);
}
```

## Fonts

Fonts are set in `src/app/layout.tsx`. Replace `Geist` and `Geist_Mono` with another `next/font` family and keep the `--font-sans` and `--font-mono` variables.
