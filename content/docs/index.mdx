This is a documentation boilerplate. Pages live in `content/docs` as MDX, and the sidebar is built from the folder structure and the `meta.json` file in each folder.

## Sidebar sections

Each top-level folder becomes a collapsible section in the sidebar. Pages at the root of `content/docs` are grouped under the root `title` from `meta.json`.

## Page frontmatter

| Field          | Purpose                                              |
| -------------- | ---------------------------------------------------- |
| `title`        | Page title and default sidebar label                 |
| `description`  | Shown under the title                                |
| `icon`         | A [Lucide](https://lucide.dev/icons) icon name       |
| `sidebarTitle` | Shorter label for the sidebar                        |
| `sidebarBadge` | Small badge next to the sidebar label, such as `new` |
