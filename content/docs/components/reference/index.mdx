This folder shows how nesting works. `reference/index.mdx` becomes the folder link, and the pages
listed in `reference/meta.json` appear under it while you are inside the folder.

- [Configuration](/docs/components/reference/configuration) documents every option in one long page, to show the table of contents.
- [Frontmatter](/docs/components/reference/frontmatter) lists the fields a page can set.
