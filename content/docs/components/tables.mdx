## Markdown table

| Script              | What it does                         |
| ------------------- | ------------------------------------ |
| `bun dev`           | Starts the dev server on a free port |
| `bun run build`     | Builds for production                |
| `bun run check`     | Formats, lints and type checks       |
| `bun run typecheck` | Regenerates `.source` and runs `tsc` |

## Read rows from a type

With `path` and `name` the rows come from the source, so they cannot drift from the code. Types the props refer to are listed under the expanded row, and hovering a name shows its definition.

```mdx
<TypeTable
  path="src/shared/config/site.ts"
  name="SiteConfig"
  descriptions={{ name: "Site name.", url: "Production URL." }}
/>
```

The Bun process that reads the types runs `scripts/type-table.ts`, so `bun` must be on the path where the site is built.
