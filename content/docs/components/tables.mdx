## Markdown table

| Script              | What it does                         |
| ------------------- | ------------------------------------ |
| `bun dev`           | Starts the dev server on a free port |
| `bun run build`     | Builds for production                |
| `bun run check`     | Formats, lints and type checks       |
| `bun run typecheck` | Regenerates `.source` and runs `tsc` |

## Alignment

| Size   | Width |    Used for     |
| :----- | ----: | :-------------: |
| Small  |  14px |  Sidebar links  |
| Medium |  16px |     Buttons     |
| Large  |  18px | Section headers |

Expand a row to see the full type. Types are highlighted as TypeScript, unions are listed one member per line, and `default` is highlighted too. Pass `typeDescription` to override the generated declaration.
